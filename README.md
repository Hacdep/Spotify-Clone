# Spotify Clone

## Ishga tushirish

Kutubxona ma'lumotlari `db.json` faylida saqlanadi. API serveri va Vite dasturini
alohida terminallarda ishga tushiring:

```sh
npm run server
```

```sh
npm run dev
```

`db.json`ni o'zgartirgandan so'ng, yangilangan ma'lumotlarni ko'rish uchun
brauzer sahifasini yangilang. Kutubxona API manzili `http://localhost:3001/library`.
